# Community guidelines

Welcome to the NEBØA DJ Studio open-source community.

- Be respectful of all contributors, DJ styles, backgrounds and experience levels.
- Give actionable feedback, with reproducible synthetic test cases when possible.
- Avoid personal attacks, harassment, discrimination, unwanted sexual attention and doxxing.
- Never share copyrighted recordings, private DJ libraries, USB database dumps, secrets or another person's contact details without permission.
- Maintainers may edit or remove off-topic, abusive or privacy-violating material and restrict participation to protect users.

If there is a problem, contact the maintainer privately using the GitHub account's contact method or a GitHub issue without personal data. For security vulnerabilities, follow [SECURITY.md](SECURITY.md).
